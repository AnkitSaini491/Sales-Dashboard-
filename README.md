# Sales Analytics Dashboard

An interactive sales dashboard built using Python, Pandas, Plotly and Streamlit.

## Features

- Total Sales
- Total Profit
- Total Orders
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Top 10 Products

## Technologies Used

- Python
- Pandas
- Plotly
- Streamlit

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
